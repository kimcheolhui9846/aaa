# 규칙과 사전 체험 체크리스트

## 사전 체험 15분 체크리스트

시험 환경에서 사전 체험이 가능할 때 아래 7개만 확인한다. 각 항목은 "안 되면"의 대체 경로를 따른다.

1. **셸 종류 확인** (bash / PowerShell / 없음)
   - 안 되면 → 셸이 없으면 `AGENTS.md`와 `.agents/` 폴더를 작업 공간에 수동 복사한다.
2. **`git`, `python`, `node` 존재**
   - 안 되면 → `git`이 없으면 키트를 복제할 수 없으므로 수동 복사. `python`(3.9+)이 없으면 셸 전용 모드(PARTIAL). `node`가 없으면 MCP 없이 진행(`--no-mcp`).
3. **공개 GitHub 접근 가능 여부** (`git clone`만으로 확인, 별도 네트워크 탐지 없음)
   - 안 되면 → 키트를 받을 수 없으므로 키트 없이 진행하고 필요하면 수동 복사.
4. **스크립트 실행 가능 여부**
   - 플랫폼 터미널에서 안 되면 → Codex에게 설치 명령을 실행해 달라고 한다(코파 환경에서 확인된 경로, 아래 "사전 체험 결과").
   - 그것도 안 되면 → 스크립트를 우회하지 말고 `AGENTS.md`와 `.agents/` 폴더를 작업 공간에 수동 복사한다.
5. **Codex에서 `/skills`로 키트 Skill 표시 여부**
   - Codex는 **키트를 설치한 작업 공간에서** 실행해야 한다. 다른 폴더에서 띄우면 키트 Skill이 보이지 않는다.
   - 안 되면 → `AGENTS.md`만으로 진행한다. 위치(작업 공간 루트)를 다시 확인한다.
6. **`/mcp` 또는 `codex mcp list`로 MCP 표시 여부**
   - MCP는 Codex가 작업 공간을 **신뢰(trust)**해야만 켜진다. Skill과 AGENTS.md는 신뢰와 무관하게 읽힌다.
   - 안 되면 → Codex를 다시 열어 신뢰 확인창에서 신뢰를 고른다. 확인창이 없거나 그래도 안 보이면 MCP 없이 진행한다.
7. **설치한 파일이 세션 재시작 후 유지되는지**
   - 안 되면 → 세션을 시작할 때마다 키트를 다시 실행한다(멱등). 실행이 불가하면 수동 복사.

이 목록에는 감독·보안 기능을 탐지하거나 시험하는 항목이 없다. 앞으로도 넣지 않는다.

## 사전 체험 결과 (2026-10-30, 사용자 보고)

| 항목 | 결과 |
|---|---|
| 플랫폼 터미널에서 설치 명령 실행 | 실패(오류 메시지 미기록) |
| Codex에게 설치 명령 실행 요청 | 설치됨. 키트 Skill이 `/skills`에 표시 |
| `/mcp`에 `sequential-thinking` | 표시되지 않음. 원인 미확인(신뢰 여부, 세션 재시작, `node` 유무 중 하나로 추정) |
| 키트 외 Skill | 없음(환경 기본 상태) |

당일 절차: Codex에게 설치 명령 실행 → `Status: READY` 확인 → Codex 세션 재시작 → 신뢰 선택 → `/skills` 확인. MCP는 한 번 확인하고 안 되면 없이 진행한다.

## 하지 않는 것

- 시험 중 GitHub push, 원격 동기화, 릴리스. 이 키트에는 그런 자동화가 없다.
- 사용자 전역 `~/.codex`, `~/.agents` 수정.
- 외부 모델·API 연결, Computer Use, 브라우저·감독 앱 조작.
- 서술형 답안 자동화.
- 실제 시험 콘텐츠의 사용·추측·수집.
- `curl | bash` 방식 설치. 복제와 실행은 분리돼 있다.

시험 중에는 운영 환경이 제공하는 Codex만 쓴다. 공식 시험 안내가 이 문서와 다르면 공식 안내가 우선한다.
